# Podcast-Blogs

A collection of blog posts sharing thoughts and reflections on interesting podcast episodes.

## 🌐 Live Site

Visit the blog at: **[https://adityak6798.github.io/Podcast-Blogs/](https://adityak6798.github.io/Podcast-Blogs/)**

## 📖 About

Podcast Musings is a simple, static blog site built with HTML, CSS, and hosted on GitHub Pages. The site features a clean, responsive design for sharing insights and discoveries from various podcast episodes.

## 📁 Project Structure

```
Podcast-Blogs/
├── index.html              # Homepage listing all blog posts
├── _config.yml             # GitHub Pages configuration
├── README.md               # Project documentation
├── blogs/                  # Blog post directory
│   └── sample-blog-post.html   # Individual blog posts
└── css/
    └── style.css           # Site styling
```

## ✨ Features

- Clean, minimalist design
- Responsive layout for mobile and desktop
- Easy-to-read typography
- Blog post listing with excerpts
- Individual post pages with article formatting
- Blockquote styling for memorable quotes

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/adityak6798/Podcast-Blogs.git
   ```

2. Open `index.html` in your browser to preview the site locally.

### Adding a New Blog Post

1. Create a new HTML file in the `blogs/` directory (e.g., `blogs/my-new-post.html`)
2. Use the existing `sample-blog-post.html` as a template
3. Update the content with your podcast thoughts
4. Add an entry to `index.html` in the blog list section
